# Ícone ClipX

Imagem criada com o gerador integrado de imagens do Codex em 21/10/2026. PNG com alpha, 1254 × 1254. Arquivo original preservado. Usado no README e na identidade das janelas; o glifo monocromático da bandeja continua adequado ao menu do sistema.

## Prompt de geração

Use case: logo-brand.
Asset type: final application icon for ClipX, a local clipboard-history utility for macOS and Linux, also used as a GitHub README project icon.
Create ONE original polished square app icon, not a presentation or a contact sheet.
Subject: a bold, immediately recognizable clipboard emblem with a clever geometric X integrated into the document area using two broad crossing strokes or negative space. Keep the silhouette minimal and distinctive. The emblem must remain readable at 24, 32, and 48 pixels.
Composition: centered front view, occupying roughly 84% of the square canvas. A graphite near-black rounded-square tile (#18181B) with generous rounded corners. Inside it, a warm off-white clipboard silhouette with a simple thick rounded top clip, and a restrained coral accent (#FF766D) forming the integrated X. Strong hierarchy and even optical spacing, ample separation between emblem and tile edges.
Style: precise contemporary desktop utility identity, clean vector-like geometry, predominantly flat colors, subtle edge polish only, sober and refined. No thin outlines, tiny details, small text or decorative sparkles. No photorealism, no scene, no mockup, no perspective, no extruded 3D, no gradients or dramatic shadows. Do not imitate any existing brand mark.
Text: none; no wordmark, no letters except the abstract geometric X motif.
Background outside the rounded-square icon tile must be genuinely transparent with alpha, no solid canvas, no checkerboard pattern. Produce the single final high-resolution square raster icon.
